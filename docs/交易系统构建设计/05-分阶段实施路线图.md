> 本文档定义 A 股量化分析 Agent 系统的 6 个实施阶段。

```
Phase 0 ────── Phase 1 ────── Phase 2 ────── Phase 3 ────── Phase 4 ────── Phase 5 ────── Phase 6

 (1天)         (2-3天)        (2-3天)        (3-5天)        (5-7天)        (5-7天)        (持续)
```

```python
# scripts/verify-data.py
"""验证 AKShare 和 Tushare 数据访问"""

import akshare as ak
import tushare as ts
import os

def verify_akshare():
    """验证 AKShare 数据访问"""
    print("=" * 40)
    print("AKShare Data Verification")
    print("=" * 40)

    # 测试实时行情
    df = ak.stock_zh_a_spot_em()
    print(f"[OK] 实时行情: {len(df)} 只股票")
    print(f"     列: {list(df.columns[:8])}")

    # 测试历史数据
    df = ak.stock_zh_a_hist(
        symbol="000001", period="daily",
        start_date="20240101", end_date="20241231",
        adjust="qfq"
    )
    print(f"[OK] 平安银行日线: {len(df)} 条记录")

    # 测试指数成分
    df = ak.index_stock_cons_csindex(symbol="000300")
    print(f"[OK] 沪深300成分: {len(df)} 只")

    # 测试北向资金
    df = ak.stock_hsgt_north_net_flow_in_em(indicator="北上")
    print(f"[OK] 北向资金: {len(df)} 天记录")


def verify_tushare():
    """验证 Tushare 数据访问"""
    print("\n" + "=" * 40)
    print("Tushare Data Verification")
    print("=" * 40)

    token = os.environ.get("TUSHARE_TOKEN", "")
    if not token:
        print("[SKIP] TUSHARE_TOKEN 未设置，跳过验证")
        return

    pro = ts.pro_api(token)

    # 测试日线数据
    df = pro.daily(ts_code="000001.SZ", start_date="20240101", end_date="20241231")
    print(f"[OK] 平安银行日线: {len(df)} 条记录")

    # 测试财务指标
    df = pro.fina_indicator(ts_code="000001.SZ")
    print(f"[OK] 财务指标: {len(df)} 条记录")

    # 测试指数权重
    df = pro.index_weight(index_code="399300.SZ", start_date="20240101")
    print(f"[OK] 沪深300权重: {len(df)} 条记录")


if __name__ == "__main__":
    verify_akshare()
    verify_tushare()
    print("\nAll verification passed!")
```

#### 1.1 编写 SKILL.md

```markdown
# factor-screen

> 基于多因子模型的 A 股股票筛选技能

## 触发条件

Triggers when: 用户要求筛选股票、查找符合条件的股票、多因子选股

Skips when: 用户要求深度分析单只股票（用 financial-analysis）

## 输入

| 参数 | 类型 | 必需 | 说明 |
|------|------|------|------|
| universe | string | 否 | 股票池，默认 "沪深300" |
| filters | string | 是 | 筛选条件，自然语言 |
| sort_by | string | 否 | 排序字段，默认 "综合得分" |
| limit | number | 否 | 返回数量，默认 20 |

## 输出

Markdown 表格，包含以下列：
- 代码、名称、行业
- 用户指定的因子值
- 综合得分和排名

## 工具依赖

- `akshare.stock_zh_a_spot` — 实时行情（PE、PB、市值）
- `akshare.index_stock_cons` — 指数成分股
- `tushare.fina_indicator` — 财务指标（ROE、毛利率等）
- `tushare.index_weight` — 时点成分权重

## 执行步骤

1. **解析输入**: 从用户自然语言中提取筛选条件
2. **确定股票池**: 根据 universe 参数获取成分股列表
3. **获取数据**:
   - 行情数据（PE、PB、市值、涨跌幅）
   - 财务指标（ROE、毛利率、净利率、营收增速）
4. **应用筛选**: 根据条件过滤
5. **排序输出**: 按 sort_by 排序，取 top N
```

#### 1.2 编写 prompt.md

```markdown
你正在执行 factor-screen 技能。

## 步骤

1. 从用户输入中识别以下信息：
   - 股票池（默认沪深300）
   - 筛选条件（如 ROE>15%, PE<20, 市值>100亿）
   - 排序方式（默认综合得分）
   - 返回数量（默认 20）

2. 获取股票池成分股：
   - 调用 akshare.index_stock_cons 或 tushare.index_weight

3. 获取行情和财务数据：
   - 调用 akshare.stock_zh_a_spot 获取 PE、PB、市值
   - 调用 tushare.fina_indicator 获取 ROE、毛利率等

4. 合并数据并应用筛选条件

5. 计算综合得分（如有多因子）：
   - 每个因子按百分位排名
   - 等权或指定权重加权

6. 输出 Markdown 表格

## 输出格式

### 筛选结果

筛选条件: <条件>
股票池: <股票池>
筛选日期: <日期>

| 排名 | 代码 | 名称 | 行业 | <因子列> | 综合得分 |
|------|------|------|------|---------|---------|
| 1 | 000858 | 五粮液 | 食品饮料 | ... | 92.5 |
| ... | ... | ... | ... | ... | ... |

共筛选出 N 只股票。
```

### 关键任务

#### 4.1 financial-analysis 技能

```
触发: 用户要求分析某只股票的财务状况
工具: tushare.income, tushare.balancesheet, tushare.cashflow, tushare.fina_indicator
输出: 财务分析报告（杜邦分析、趋势分析、行业对比）
```

核心提示词要点：
1. 获取最近 3-5 年的三大报表数据
2. 计算 ROE 分解（净利率 x 资产周转率 x 权益乘数）
3. 计算偿债能力指标（流动比率、速动比率、资产负债率）
4. 计算盈利能力指标（毛利率、净利率、ROIC）
5. 计算成长性指标（营收增速、利润增速）
6. 与同行业公司对比（中位数、百分位）
7. 识别财务风险信号

#### 4.2 factor-research 技能

```
触发: 用户要求研究某因子的有效性、因子回测
工具: akshare.stock_zh_a_hist, tushare.index_weight, tushare.fina_indicator
输出: 因子研究报告（IC分析、分层回测、多空收益）
```

核心提示词要点：
1. 定义因子计算方法（动量、价值、质量、波动率等）
2. 获取全市场历史数据
3. 计算每期因子暴露度
4. 计算因子 IC（Information Coefficient）
5. 按因子值分十分位，计算每组收益
6. 计算多空收益和夏普比率
7. 分析因子的衰减和换手特征

#### 4.3 backtest-engine 技能

```
触发: 用户要求回测某策略、/backtest 命令
工具: akshare.stock_zh_a_hist, tushare.index_weight, internal-store
输出: 回测报告（净值曲线、绩效指标、持仓明细）
```

核心提示词要点：
1. 解析策略描述（因子、调仓频率、股票池、权重）
2. 获取时点正确的历史数据（使用 index_weight 避免前视偏差）
3. 按调仓频率生成信号
4. 模拟交易执行（滑点 0.2%、手续费 0.1%）
5. 计算绩效指标：
   - 年化收益率、夏普比率、最大回撤
   - 超额收益（相对基准）
   - Calmar 比率、Sortino 比率

```python
# 概念设计：编排器
class AgentOrchestrator:

    """

    def plan(self, user_request: str) -> list[AgentTask]:
        """
        根据用户请求，生成 Agent 执行计划。
        返回有序的任务列表。
        """
        ...

    def execute(self, plan: list[AgentTask]) -> dict:
        """
        按计划依次执行 Agent 任务。
        上游 Agent 的输出作为下游 Agent 的输入。
        """
        ...

    def summarize(self, results: dict) -> str:
        """
        汇总所有 Agent 的输出，生成最终报告。
        """
        ...
```
