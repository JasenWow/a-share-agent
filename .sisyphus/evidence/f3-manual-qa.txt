## OBSERVATIONS

CRITICAL FINDING: The MCP server uses streaming SSE responses. The curl command
format specified in the test plan (/tools/call endpoint) is INCORRECT for this
server implementation. The actual MCP protocol requires:

1. POST /mcp/ (not /tools/call)
2. Accept: application/json, text/event-stream
3. Session ID via mcp-session-id header (obtained from initialize response)
4. JSON-RPC 2.0 envelope with method, id, params

The root endpoint returns 404, /tools/call returns 404.
